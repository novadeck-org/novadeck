# Glossary

The names Novadeck shows people, and what each one means. Use them in the app, the docs and
the release notes, and don't call one thing by another's name. A term earns a place here once
the app shows it; keep the list short.

- **Project**: a folder you work in, usually a repository. Pin one to reach it by shortcut.
- **Session**: a group of a project's terminals, listed in the Sessions panel. An agent's own
  conversation, which it resumes after a restart, is the agent's, not a Novadeck session.
- **Terminal**: one shell, where you run an agent or anything else. Its row in the sidebar is
  its tab, and Grid and Canvas show it as a window.
- **View**: how the terminals are laid out: **Focus** (one terminal), **Grid** (side by
  side) or **Canvas** (a board). These three are the only views; **Zen** hides everything
  else in any of them.
- **Companion Pane**: the pane beside a terminal, with a tab per thing it holds: a page, a
  file, a plan, changes, Messages. It is not a view.
- **Agent Chat**: an agent's terminal shown as a chat instead of its screen.
- **Sidebar**: the panels down the window's side: Terminals, Inbox, Sessions, Worktrees,
  Files and History.
- **Inbox**: where agents' questions, permissions, plans and done reports wait for you.
- **Handle**: a terminal's word, such as `@moth`, that agents use to message it.
- **Team**: agents one **lead** started and works with; each of them is a **teammate**.
